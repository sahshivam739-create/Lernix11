1. Statements

📖 Concept

A statement is a sentence which is either true or false, but not both.

A statement must have a definite truth value.

✏️ Ex 1

Is "5 + 3 = 8" a statement?

✅ Solution

The sentence is definitely true.

Therefore, it is a statement.

✏️ Ex 2

Is "Close the door" a statement?

✅ Solution

It is an instruction and does not have a truth value.

Therefore, it is not a statement.

🔗 🔵 🔵

2. Negation of a Statement

The negation of a statement changes its truth value.

If a statement is true, its negation is false, and vice versa.

Negation of p is written as:

~p

✏️ Ex 1

Write the negation of:

"7 is an odd number."

✅ Solution

The given statement is true.

Negation: "7 is not an odd number."

✏️ Ex 2

Write the negation of:

"10 is a prime number."

✅ Solution

"10 is not a prime number."

🔗 ➕ 🔗

3. Compound Statements

Two or more simple statements can be combined to form a compound statement.

Common logical connectives are:

• AND

• OR

• IF...THEN

• IF AND ONLY IF

✏️ Ex 1

Let p: "2 is even" and q: "3 is odd". Write p AND q.

✅ Solution

p ∧ q means both p and q are true.

"2 is even and 3 is odd."

✏️ Ex 2

Let p: "5 is even" and q: "7 is odd". Write p OR q.

✅ Solution

p ∨ q means at least one statement is true.

Here q is true.

Therefore, p OR q is true.

🔵 ∧ 🔵

4. Conjunction

The conjunction of two statements p and q is written as p ∧ q.

It is true only when both p and q are true.

p ∧ q = "p and q"

✏️ Ex 1

p is true and q is true. Find the truth value of p ∧ q.

✅ Solution

Both p and q are true.

p ∧ q is True.

✏️ Ex 2

p is true and q is false. Find p ∧ q.

✅ Solution

For conjunction, both must be true.

p ∧ q is False.

🔵 ∨ 🔵

5. Disjunction

The disjunction of p and q is written as p ∨ q.

It is false only when both p and q are false.

p ∨ q = "p or q"

✏️ Ex 1

p is true and q is false. Find p ∨ q.

✅ Solution

At least one statement is true.

p ∨ q is True.

✏️ Ex 2

p is false and q is false. Find p ∨ q.

✅ Solution

Both statements are false.

p ∨ q is False.

➡️ 🔵 🔵

6. Conditional Statements

A conditional statement has the form:

"If p, then q."

It is written as p → q.

p → q

Read as: "If p then q."

✏️ Ex 1

Write the conditional statement:

p: A number is divisible by 4.

q: The number is even.

✅ Solution

If a number is divisible by 4, then it is even.

✏️ Ex 2

For p → q, p is true and q is false. Find the truth value.

✅ Solution

A conditional statement is false only when p is true and q is false.

Therefore, p → q is False.

↔️ 🔵 🔵

7. Biconditional Statement

A biconditional statement is written as p ↔ q.

It means "p if and only if q."

p ↔ q is true when p and q have the same truth value.

✏️ Ex 1

If p is true and q is true, find p ↔ q.

✅ Solution

Both have the same truth value.

p ↔ q is True.

✏️ Ex 2

If p is true and q is false, find p ↔ q.

✅ Solution

The truth values are different.

p ↔ q is False.

📊 🧠 🔢

8. Truth Tables

A truth table shows the truth values of a compound statement for all possible combinations of truth values of its components.

For two statements p and q, there are:

2² = 4 possible combinations.

✏️ Ex 1

How many rows are required for a truth table containing two simple statements p and q?

✅ Solution

Number of combinations = 2ⁿ

Here n = 2.

2² = 4

Answer: 4 rows

✏️ Ex 2

How many combinations are possible for three statements?

✅ Solution

2³ = 8

Answer: 8 combinations

⭐ 📌 🧠

⭐ Important Revision

1. Statement has a definite truth value.

2. Negation of p = ~p

3. Conjunction = p ∧ q

4. Disjunction = p ∨ q

5. Conditional = p → q

6. Biconditional = p ↔ q

7. p ∧ q is true only when both are true.

8. p ∨ q is false only when both are false.

9. p → q is false only when p is true and q is false.

10. p ↔ q is true when p and q have the same truth value.

11. For n statements, possible combinations = 2ⁿ.

1. Introduction to Binomial Theorem

📖 Concept

A binomial is an algebraic expression containing two terms.

Examples:

x + y, a + b, 2x + 3

The Binomial Theorem gives a systematic way to expand positive integral powers of a binomial.

(a+b)ⁿ = Σ ⁿCᵣ aⁿ⁻ʳ bʳ for r = 0 to n

✏️ Ex 1

Expand:

(x + 2)²

✅ Solution

(x+2)²

= x² + 2(x)(2) + 2²

= x² + 4x + 4

Answer: x² + 4x + 4

✏️ Ex 2

Expand:

(a + b)³

✅ Solution

(a+b)³

= a³ + 3a²b + 3ab² + b³

Answer: a³ + 3a²b + 3ab² + b³

2. General Term

The general term in the expansion of (a+b)ⁿ is:

Tᵣ₊₁ = ⁿCᵣ aⁿ⁻ʳ bʳ

✏️ Ex 1

Find the 3rd term of:

(x + 2)⁵

✅ Solution

For the 3rd term:

r + 1 = 3

r = 2

T₃ = ⁵C₂ x³(2²)

= 10 × x³ × 4

= 40x³

✏️ Ex 2 — 🔴 Hard

Find the 4th term of:

(2x + 3)⁶

✅ Solution

For the 4th term:

r = 3

T₄ = ⁶C₃ (2x)³(3)³

= 20 × 8x³ × 27

= 4320x³

🔢 ⭐ 🧮

3. Binomial Coefficients

The coefficients in a binomial expansion are called binomial coefficients.

ⁿCᵣ = n!/[r!(n−r)!]

ⁿC₀ = ⁿCₙ = 1

ⁿCᵣ = ⁿCₙ₋ᵣ

✏️ Ex 1

Find:

⁶C₂

✅ Solution

⁶C₂ = 6!/(2!4!)

= (6×5)/(2×1)

= 15

✏️ Ex 2

Find:

⁸C₆

✅ Solution

Using:

⁸C₆ = ⁸C₂

= 8×7/2

= 28

🔍 🧠 📌

4. Middle Term

The number of terms in the expansion of (a+b)ⁿ is n+1.

If n is even, there is one middle term.

If n is odd, there are two middle terms.

If n is even: Middle term = (n/2 + 1)th term

If n is odd: Middle terms = ((n+1)/2)th and ((n+3)/2)th terms

✏️ Ex 1

Find the middle term of:

(x + 1)⁶

✅ Solution

n = 6

Number of terms = 7

Middle term = 4th term

T₄ = ⁶C₃ x³

= 20x³

Middle term = 20x³

✏️ Ex 2 — 🔴 Hard

Find the middle terms of:

(x + 2)⁷

✅ Solution

n = 7

There are 8 terms.

Middle terms are 4th and 5th.

T₄ = ⁷C₃ x⁴(2³)

= 35 × 8x⁴

= 280x⁴

T₅ = ⁷C₄ x³(2⁴)

= 35 × 16x³

= 560x³

🔢 🎯 🧠

5. Particular Term

The general term formula can be used to find any particular term of a binomial expansion.

✏️ Ex 1

Find the 5th term of:

(2x + 1)⁶

✅ Solution

For 5th term:

r = 4

T₅ = ⁶C₄ (2x)²

= 15 × 4x²

= 60x²

✏️ Ex 2 — 🔴 Hard

Find the term independent of x in:

(x² + 1/x)⁶

✅ Solution

General term:

Tᵣ₊₁ = ⁶Cᵣ (x²)⁶⁻ʳ (1/x)ʳ

Power of x:

2(6−r) − r

= 12 − 3r

For independent term:

12 − 3r = 0

r = 4

Term = ⁶C₄

= 15

6. Important Binomial Identities

ⁿCᵣ = ⁿCₙ₋ᵣ

ⁿCᵣ + ⁿCᵣ₋₁ = ⁿ⁺¹Cᵣ

Σ ⁿCᵣ = 2ⁿ

Σ (−1)ʳ ⁿCᵣ = 0

✏️ Ex 1

Find the sum:

⁵C₀ + ⁵C₁ + ⁵C₂ + ⁵C₃ + ⁵C₄ + ⁵C₅

✅ Solution

Sum of coefficients = 2⁵

= 32

✏️ Ex 2

Find:

⁷C₀ − ⁷C₁ + ⁷C₂ − ⁷C₃ + ... − ⁷C₇

✅ Solution

This is:

(1−1)⁷

= 0⁷

= 0

⭐ Important Formula Revision

1. (a+b)ⁿ = Σ ⁿCᵣ aⁿ⁻ʳbʳ

2. Tᵣ₊₁ = ⁿCᵣ aⁿ⁻ʳbʳ

3. Number of terms = n+1

4. ⁿCᵣ = ⁿCₙ₋ᵣ

5. ⁿC₀ = ⁿCₙ = 1

6. Sum of coefficients = 2ⁿ

7. Alternating sum of coefficients = 0

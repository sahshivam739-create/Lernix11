1. Introduction to Sequences

📖 Concept

A sequence is an ordered list of numbers arranged according to a definite rule.

Example:

2, 4, 6, 8, 10, ...

Each number is called a term of the sequence.

✏️ Ex 1

Write the next two terms:

3, 6, 9, 12, ...

✅ Solution

Common difference = 3

12 + 3 = 15

15 + 3 = 18

Answer: 15, 18

✏️ Ex 2

Find the next two terms:

2, 4, 8, 16, ...

✅ Solution

Each term is multiplied by 2.

16 × 2 = 32

32 × 2 = 64

Answer: 32, 64

➕ 📏 🔢

2. Arithmetic Progression (AP)

An arithmetic progression is a sequence in which the difference between consecutive terms is constant.

The constant difference is called the common difference and is denoted by d.

a, a+d, a+2d, a+3d, ...

First term = a
Common difference = d
Tₙ = a + (n−1)d

✏️ Ex 1

Find the 10th term of:

2, 5, 8, 11, ...

✅ Solution

a = 2

d = 5 − 2 = 3

n = 10

T₁₀ = a + (n−1)d

= 2 + 9(3)

= 29

✏️ Ex 2

Find the 15th term of:

7, 10, 13, 16, ...

✅ Solution

a = 7

d = 3

T₁₅ = 7 + 14(3)

= 49

🔍 🔢 📌

3. Finding a Particular Term of AP

The nth term formula can be used to find which term of an AP is equal to a given number.

Tₙ = a + (n−1)d

✏️ Ex 1

Which term of the AP 5, 9, 13, 17, ... is 81?

✅ Solution

a = 5, d = 4

81 = 5 + (n−1)4

76 = 4(n−1)

19 = n−1

n = 20

Therefore, 81 is the 20th term.

✏️ Ex 2

Which term of the AP 3, 7, 11, 15, ... is 99?

✅ Solution

a = 3, d = 4

99 = 3 + (n−1)4

96 = 4(n−1)

24 = n−1

n = 25

Σ ➕ 🔢

4. Sum of n Terms of an AP

The sum of the first n terms of an AP is represented by Sₙ.

Sₙ = n/2 [2a + (n−1)d]

Also,
Sₙ = n/2 (a + l)
where l = last term

✏️ Ex 1

Find the sum of the first 10 terms of:

2, 5, 8, 11, ...

✅ Solution

a = 2, d = 3, n = 10

S₁₀ = 10/2 [2(2) + 9(3)]

= 5[4 + 27]

= 5 × 31

= 155

✏️ Ex 2

Find the sum of the first 20 natural numbers.

✅ Solution

1 + 2 + 3 + ... + 20

S₂₀ = 20/2 [2 + 19]

= 10 × 21

= 210

📌 ➕ 📌

5. Important Properties of AP

Some useful properties of an arithmetic progression are:

If a, b, c are consecutive terms of an AP:

2b = a + c

Therefore,
b = (a+c)/2

✏️ Ex 1

Find x if 5, x, 17 are consecutive terms of an AP.

✅ Solution

2x = 5 + 17

2x = 22

x = 11

✏️ Ex 2

If 4, x, 20 are consecutive terms of an AP, find x.

✅ Solution

2x = 4 + 20

2x = 24

x = 12

📐 ➕ 🔢

6. Arithmetic Mean

The arithmetic mean of two numbers a and b is the number which is equally spaced from both numbers.

AM = (a+b)/2

✏️ Ex 1

Find the arithmetic mean of 8 and 12.

✅ Solution

AM = (8 + 12)/2

= 10

✏️ Ex 2

Insert three arithmetic means between 2 and 18.

✅ Solution

The AP is:

2, A, B, C, 18

There are 4 equal gaps.

d = (18−2)/4

d = 4

Therefore:

2, 6, 10, 14, 18

The three arithmetic means are:

6, 10, 14

✖️ 📈 🔢

7. Geometric Progression (GP)

A geometric progression is a sequence in which the ratio between consecutive terms is constant.

The constant ratio is called the common ratio and is denoted by r.

a, ar, ar², ar³, ...

First term = a
Common ratio = r
Tₙ = arⁿ⁻¹

✏️ Ex 1

Find the 5th term of:

2, 6, 18, 54, ...

✅ Solution

a = 2

r = 6/2 = 3

T₅ = 2 × 3⁴

= 162

✏️ Ex 2

Find the 6th term of:

5, 10, 20, 40, ...

✅ Solution

a = 5

r = 2

T₆ = 5 × 2⁵

= 160

📌 ✖️ 📌

8. Important Properties of GP

If a, b, c are consecutive terms of a GP, then:

b² = ac

Therefore,
b = √ac

✏️ Ex 1

Find x if 4, x, 36 are consecutive terms of a GP.

✅ Solution

x² = 4 × 36

x² = 144

x = 12

✏️ Ex 2

Find x if 9, x, 25 are consecutive positive terms of a GP.

✅ Solution

x² = 9 × 25

x² = 225

x = 15

Σ ✖️ 📊

9. Sum of n Terms of a GP

For r ≠ 1:

Sₙ = a(rⁿ−1)/(r−1)

or

Sₙ = a(1−rⁿ)/(1−r)

✏️ Ex 1

Find the sum of the first 5 terms of:

2, 4, 8, 16, ...

✅ Solution

a = 2, r = 2, n = 5

S₅ = 2(2⁵−1)/(2−1)

= 2(32−1)

= 62

✏️ Ex 2

Find the sum:

3 + 6 + 12 + 24 + 48

✅ Solution

a = 3, r = 2, n = 5

S₅ = 3(2⁵−1)/(2−1)

= 3 × 31

= 93

∞ 🔄 📉

10. Infinite GP

An infinite GP has infinitely many terms. Its sum exists when the absolute value of the common ratio is less than 1.

S∞ = a/(1−r)

Condition: |r| < 1

✏️ Ex 1

Find the sum:

1 + 1/2 + 1/4 + 1/8 + ...

✅ Solution

a = 1

r = 1/2

S∞ = 1/(1−1/2)

= 2

✏️ Ex 2

Find the sum:

3 + 1.5 + 0.75 + ...

✅ Solution

a = 3

r = 1/2

S∞ = 3/(1−1/2)

= 6

⭐ 📐 ✖️

11. AM and GM Relation

For two positive numbers a and b, the arithmetic mean is always greater than or equal to the geometric mean.

AM ≥ GM

(a+b)/2 ≥ √ab

Equality holds when: a = b

✏️ Ex 1

Find AM and GM of 4 and 16.

✅ Solution

AM = (4+16)/2

= 10

GM = √(4×16)

= √64

= 8

Therefore AM ≥ GM.

🔢 ➕ ✖️

12. Special Series

Some standard sums are frequently used in Class 11 problems.

1 + 2 + 3 + ... + n
= n(n+1)/2

1² + 2² + 3² + ... + n²
= n(n+1)(2n+1)/6

1³ + 2³ + 3³ + ... + n³
= [n(n+1)/2]²

✏️ Ex 1

Find 1 + 2 + 3 + ... + 50.

✅ Solution

Sum = n(n+1)/2

= 50 × 51 / 2

= 1275

✏️ Ex 2

Find 1² + 2² + 3² + 4² + 5².

✅ Solution

n = 5

Sum = 5×6×11/6

= 55

⭐ Important Formula Revision

1. AP nth term: Tₙ = a + (n−1)d

2. AP sum: Sₙ = n/2[2a+(n−1)d]

3. AP consecutive terms: 2b = a+c

4. Arithmetic Mean: AM = (a+b)/2

5. GP nth term: Tₙ = arⁿ⁻¹

6. GP consecutive terms: b² = ac

7. GP sum: Sₙ = a(rⁿ−1)/(r−1)

8. Infinite GP: S∞ = a/(1−r), |r| < 1

9. Geometric Mean: GM = √ab

10. AM ≥ GM for positive numbers.

11. 1+2+...+n = n(n+1)/2

12. 1²+2²+...+n² = n(n+1)(2n+1)/6

13. 1³+2³+...+n³ = [n(n+1)/2]²

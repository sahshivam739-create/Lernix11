1. Introduction to Sets

🔵 🔴 🟢

📖 Concept

A set is a well-defined collection of distinct objects. The objects of a set are called its elements or members.

A = {1, 2, 3, 4}

Here 1, 2, 3 and 4 are elements of set A.

✏️ Ex 1

Write the set of first five natural numbers.

✅ Solution

The first five natural numbers are:

1, 2, 3, 4, 5

Answer: N = {1, 2, 3, 4, 5}

✏️ Ex 2

Is the collection of vowels in English alphabet a set?

✅ Solution

Yes. The vowels are clearly defined as:

{a, e, i, o, u}

Answer: Yes, it is a set.

2. Representation of Sets

📝 { } 🔢

📖 Methods

A set can be represented mainly by:

1. Roster form

2. Set-builder form

3. Descriptive form

✏️ Ex 1

Represent the set of vowels in roster form.

✅ Solution

The vowels are a, e, i, o and u.

A = {a, e, i, o, u}

✏️ Ex 2

Write A = {2, 4, 6, 8, 10} in set-builder form.

✅ Solution

All elements are even natural numbers less than 12.

A = {x : x is an even natural number and x < 12}

3. Types of Sets

🔵 🔵 ⚪ ∅

📖 Important Types

Empty set, singleton set, finite set, infinite set and equal sets are important types of sets.

✏️ Ex 1

Identify the type of set: A = {5}

✅ Solution

Set A contains exactly one element.

Answer: A is a singleton set.

✏️ Ex 2

Identify the type of set: B = {x : x is a natural number and x < 1}

✅ Solution

There is no natural number less than 1.

Therefore B has no element.

Answer: B is an empty set.

4. Subsets

A ⊂ B

📖 Definition

Set A is a subset of set B if every element of A is also an element of B.

A ⊆ B

Number of subsets of a set having n elements = 2ⁿ

✏️ Ex 1

If A = {1, 2} and B = {1, 2, 3, 4}, is A a subset of B?

✅ Solution

Every element of A is present in B.

Therefore A ⊆ B.

✏️ Ex 2

Find the number of subsets of A = {a, b, c}.

✅ Solution

Number of elements = 3

Number of subsets = 2³

= 8

Answer: 8 subsets

5. Power Set

⚡ { } 📚

📖 Definition

The collection of all subsets of a set A is called the power set of A and is denoted by P(A).

✏️ Ex 1

Find P(A), if A = {1, 2}.

✅ Solution

Subsets are:

∅, {1}, {2}, {1,2}

P(A) = {∅, {1}, {2}, {1,2}}

✏️ Ex 2

Find the number of elements in P(A), if A has 4 elements.

✅ Solution

Number of subsets = 2ⁿ

= 2⁴

= 16

Answer: 16

6. Universal Set

🌍 U 🔵

📖 Definition

A universal set contains all the objects under consideration. It is generally denoted by U.

✏️ Ex 1

If U = {1,2,3,4,5} and A = {1,2}, find the elements of U which are not in A.

✅ Solution

Elements of U not present in A are:

{3,4,5}

Answer: {3,4,5}

✏️ Ex 2

Can the universal set be different for different problems?

✅ Solution

Yes. The universal set depends on the objects under consideration.

Answer: Yes.

7. Venn Diagrams

⭕ 🔵 ⭕

📖 Concept

Venn diagrams represent sets using closed curves, usually circles, inside a rectangle representing the universal set.

✏️ Ex 1

If A = {1,2,3} and B = {3,4,5}, which element is common?

✅ Solution

The common element is 3.

Answer: 3

✏️ Ex 2

If two sets have no common element, what are they called?

✅ Solution

Sets having no common element are called disjoint sets.

Answer: Disjoint sets.

8. Union of Sets

A ∪ B

📖 Definition

The union of A and B contains all elements which belong to A or B or both.

A ∪ B

✏️ Ex 1

A = {1,2,3}, B = {3,4,5}. Find A ∪ B.

✅ Solution

Take all distinct elements from both sets.

A ∪ B = {1,2,3,4,5}

Answer: {1,2,3,4,5}

✏️ Ex 2

If A = {a,b} and B = {c,d}, find A ∪ B.

✅ Solution

A ∪ B = {a,b,c,d}

Answer: {a,b,c,d}

9. Intersection of Sets

A ∩ B

📖 Definition

The intersection of A and B contains only the elements common to both sets.

✏️ Ex 1

A = {1,2,3} and B = {2,3,4}. Find A ∩ B.

✅ Solution

Common elements are 2 and 3.

A ∩ B = {2,3}

✏️ Ex 2

A = {1,2} and B = {3,4}. Find A ∩ B.

✅ Solution

There is no common element.

A ∩ B = ∅

10. Difference of Sets

A − B

📖 Definition

A − B contains those elements of A which are not present in B.

✏️ Ex 1

A = {1,2,3,4} and B = {3,4,5}. Find A − B.

✅ Solution

Elements of A which are not in B are 1 and 2.

A − B = {1,2}

✏️ Ex 2

A = {a,b,c} and B = {b,c,d}. Find B − A.

✅ Solution

The element present in B but not in A is d.

B − A = {d}

11. Complement of a Set

Aᶜ 🌍

📖 Definition

The complement of A contains all elements of the universal set which are not in A.

Aᶜ = U − A

✏️ Ex 1

U = {1,2,3,4,5} and A = {1,2}. Find Aᶜ.

✅ Solution

Aᶜ = U − A

Aᶜ = {3,4,5}

Answer: {3,4,5}

✏️ Ex 2

If U = {a,b,c,d} and A = {a,c,d}, find Aᶜ.

✅ Solution

Only b is present in U but not in A.

Aᶜ = {b}

12. Important Laws of Sets

📚 ⚖️ { }
A ∪ ∅ = A

A ∩ U = A

A ∪ A = A

A ∩ A = A

A ∪ Aᶜ = U

A ∩ Aᶜ = ∅

✏️ Ex 1

If A = {1,2,3}, find A ∪ A.

✅ Solution

A ∪ A = A

Answer: {1,2,3}

✏️ Ex 2

Find A ∩ Aᶜ.

✅ Solution

A and Aᶜ have no common element.

A ∩ Aᶜ = ∅

🔥 Mixed Questions

These questions combine different topics of Sets.

✏️ Mixed Ex 1

If U = {1,2,3,4,5,6,7,8}, A = {1,2,3,4} and B = {3,4,5,6}, find A ∪ B, A ∩ B and Aᶜ.

✅ Solution

A ∪ B = {1,2,3,4,5,6}

A ∩ B = {3,4}

Aᶜ = {5,6,7,8}

Final Answer:
A ∪ B = {1,2,3,4,5,6}
A ∩ B = {3,4}
Aᶜ = {5,6,7,8}

✏️ Mixed Ex 2

In a class of 40 students, 25 like Mathematics, 20 like Physics and 10 like both. Find the number of students who like at least one of the two subjects.

✅ Solution

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

= 25 + 20 − 10

= 35

Answer: 35 students

✏️ Mixed Ex 3

If a set contains 5 elements, find the number of subsets and proper subsets.

✅ Solution

Number of subsets = 2⁵ = 32

Number of proper subsets = 32 − 1 = 31

Answer: 32 subsets and 31 proper subsets

✏️ Mixed Ex 4

If A = {1,2,3,4,5} and B = {2,4,6,8}, find (A ∪ B) − (A ∩ B).

✅ Solution

A ∪ B = {1,2,3,4,5,6,8}

A ∩ B = {2,4}

Therefore:

(A ∪ B) − (A ∩ B)

= {1,3,5,6,8}

Answer: {1,3,5,6,8}

✏️ Mixed Ex 5 — 🔴 JEE Level

In a group of 100 students, 60 study Mathematics, 50 study Physics and 30 study both. Find the number of students who study neither Mathematics nor Physics.

✅ Solution

n(M ∪ P) = n(M) + n(P) − n(M ∩ P)

= 60 + 50 − 30

= 80

Students studying neither:

= 100 − 80

= 20

Answer: 20 students

1. Introduction to Limits

📖 Concept

The limit of a function describes the value that the function approaches as the input approaches a particular number.

lim x→a f(x) = L

This means f(x) approaches L as x approaches a.

✏️ Ex 1

Find:

lim x→2 (x + 3)

✅ Solution

Put x = 2:

= 2 + 3

= 5

✏️ Ex 2

Find:

lim x→3 (2x + 1)

✅ Solution

Put x = 3:

= 2(3) + 1

= 6 + 1

= 7

🔢 ➗ 🔍

2. Algebraic Limits

For polynomial functions, the limit can usually be found by direct substitution.

lim x→a [f(x)] = f(a)

✏️ Ex 1

Find:

lim x→2 (x² + 3x + 1)

✅ Solution

Put x = 2:

= 2² + 3(2) + 1

= 4 + 6 + 1

= 11

✏️ Ex 2

Find:

lim x→1 (x³ + 2x² + x)

✅ Solution

Put x = 1:

= 1 + 2 + 1

= 4

➗ ✂️ 🔢

3. Limits by Factorisation

Sometimes direct substitution gives 0/0. In such cases, factorisation can be used to simplify the expression.

✏️ Ex 1

Find:

lim x→2 (x²−4)/(x−2)

✅ Solution

x²−4 = (x−2)(x+2)

Therefore:

(x−2)(x+2)/(x−2)

= x+2

Now put x = 2:

= 4

✏️ Ex 2

Find:

lim x→3 (x²−9)/(x−3)

✅ Solution

x²−9 = (x−3)(x+3)

So the expression becomes:

x+3

Put x = 3:

= 6

📈 ⚡ 🧮

4. Derivatives

The derivative of a function represents its instantaneous rate of change.

It is also related to the slope of the tangent to a curve.

Derivative of xⁿ: d/dx (xⁿ) = nxⁿ⁻¹

d/dx (c) = 0

d/dx (x) = 1

✏️ Ex 1

Find the derivative of:

y = x²

✅ Solution

dy/dx = 2x²⁻¹

dy/dx = 2x

✏️ Ex 2

Find the derivative of:

y = x³

✅ Solution

dy/dx = 3x²

Answer: 3x²

➕ ✖️ 📈

5. Derivative of Sum and Difference

The derivative of a sum or difference can be found by differentiating each term separately.

d/dx [f(x) ± g(x)] = f'(x) ± g'(x)

✏️ Ex 1

Find the derivative of:

y = x² + 3x + 5

✅ Solution

dy/dx = 2x + 3 + 0

dy/dx = 2x + 3

✏️ Ex 2

Find the derivative of:

y = 4x³ − 2x² + 7

✅ Solution

dy/dx = 12x² − 4x + 0

dy/dx = 12x² − 4x

✖️ 🔄 📈

6. Product Rule

When two functions are multiplied, the product rule is used to find the derivative.

d/dx(uv) = u(dv/dx) + v(du/dx)

✏️ Ex 1

Differentiate:

y = x(x² + 1)

✅ Solution

u = x

v = x² + 1

dy/dx = u(dv/dx) + v(du/dx)

= x(2x) + (x²+1)(1)

= 2x² + x² + 1

= 3x² + 1

✏️ Ex 2

Differentiate:

y = x²(x+3)

✅ Solution

u = x²

v = x+3

dy/dx = x²(1) + (x+3)(2x)

= x² + 2x² + 6x

= 3x² + 6x

➗ 🔄 📉

7. Quotient Rule

When one function is divided by another function, the quotient rule can be used.

d/dx(u/v) = [v(du/dx) − u(dv/dx)] / v²

✏️ Ex 1

Differentiate:

y = x²/x

✅ Solution

First simplify:

y = x

Therefore:

dy/dx = 1

✏️ Ex 2

Differentiate:

y = (x²+1)/x

✅ Solution

Rewrite:

y = x + 1/x

y = x + x⁻¹

dy/dx = 1 − x⁻²

dy/dx = 1 − 1/x²

🔗 📈 🧠

8. Chain Rule

The chain rule is used when one function is inside another function.

dy/dx = dy/du × du/dx

✏️ Ex 1

Differentiate:

y = (x²+1)³

✅ Solution

Let u = x²+1

y = u³

dy/du = 3u²

du/dx = 2x

dy/dx = 3u² × 2x

= 6x(x²+1)²

✏️ Ex 2

Differentiate:

y = (2x+1)⁴

✅ Solution

dy/dx = 4(2x+1)³ × 2

= 8(2x+1)³

⭐ 📌 🧠

⭐ Important Formula Revision

1. lim x→a f(x) = f(a), when direct substitution is valid.

2. d/dx(xⁿ) = nxⁿ⁻¹

3. d/dx(c) = 0

4. d/dx(x) = 1

5. Sum rule: (u+v)' = u'+v'

6. Product rule: (uv)' = uv' + vu'

7. Quotient rule: (u/v)' = (vu'−uv')/v²

8. Chain rule: dy/dx = dy/du × du/dx

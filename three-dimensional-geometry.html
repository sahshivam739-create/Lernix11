1. Introduction to 3D Geometry

📖 Concept

Three-dimensional geometry deals with points, lines and objects in space.

A point in three-dimensional space is represented by three coordinates:

(x, y, z)

Here x, y and z represent the position along the three coordinate axes.

✏️ Ex 1

Write the coordinates of a point whose x-coordinate is 3, y-coordinate is 4 and z-coordinate is 5.

✅ Solution

The coordinates are directly given.

Point = (3,4,5)

✏️ Ex 2

How many coordinates are required to locate a point in 3D space?

✅ Solution

Three coordinates are required:

x, y and z

Answer: 3 coordinates

📏 📐 📍

2. Distance Between Two Points

The distance between two points in three-dimensional space can be found using the 3D distance formula.

If A(x₁,y₁,z₁) and B(x₂,y₂,z₂),

AB = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]

✏️ Ex 1

Find the distance between:

A(1,2,3) and B(4,6,3)

✅ Solution

AB = √[(4−1)² + (6−2)² + (3−3)²]

= √[9 + 16 + 0]

= √25

AB = 5

✏️ Ex 2

Find the distance between (2,3,4) and (5,7,4).

✅ Solution

d = √[(5−2)² + (7−3)² + (4−4)²]

= √[9 + 16]

d = 5

📍 ➗ 📍

3. Section Formula

Section formula gives the coordinates of a point which divides the line segment joining two points in a given ratio.

If P divides A(x₁,y₁,z₁) and B(x₂,y₂,z₂) in ratio m:n,

P = ((mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n), (mz₂+nz₁)/(m+n))

✏️ Ex 1

Find the midpoint of A(2,4,6) and B(4,8,10).

✅ Solution

Midpoint =

((2+4)/2, (4+8)/2, (6+10)/2)

= (3,6,8)

✏️ Ex 2

Find the point dividing (1,2,3) and (4,5,6) in the ratio 1:2.

✅ Solution

x = [1(4)+2(1)]/3 = 2

y = [1(5)+2(2)]/3 = 3

z = [1(6)+2(3)]/3 = 4

Point = (2,3,4)

🎯 📐 📊

4. Coordinates of a Point

In 3D geometry, the position of a point is represented using ordered triplets (x,y,z).

The three coordinate planes are:

• XY-plane

• YZ-plane

• ZX-plane

XY-plane: z = 0
YZ-plane: x = 0
ZX-plane: y = 0

✏️ Ex 1

Which plane contains the point (3,4,0)?

✅ Solution

For the XY-plane:

z = 0

Here z = 0.

Therefore, the point lies in the XY-plane.

✏️ Ex 2

Which plane contains the point (0,5,7)?

✅ Solution

For the YZ-plane:

x = 0

Here x = 0.

Therefore, the point lies in the YZ-plane.

➕ ➖ 📍

5. Coordinates of Points on Axes

A point on the x-axis has y = 0 and z = 0.

A point on the y-axis has x = 0 and z = 0.

A point on the z-axis has x = 0 and y = 0.

x-axis: (x,0,0)
y-axis: (0,y,0)
z-axis: (0,0,z)

✏️ Ex 1

Check whether (5,0,0) lies on the x-axis.

✅ Solution

For x-axis:

y = 0 and z = 0

The point is (5,0,0).

Therefore, it lies on the x-axis.

✏️ Ex 2

Which axis contains the point (0,0,7)?

✅ Solution

x = 0 and y = 0.

Therefore, the point lies on the z-axis.

📊 ⭐ 📍

6. Octants

The three coordinate planes divide the entire 3D space into eight regions called octants.

The signs of x, y and z determine the position of a point.

✏️ Ex 1

What are the signs of the coordinates of a point in the first octant?

✅ Solution

In the first octant:

x > 0, y > 0, z > 0

✏️ Ex 2

In which octant does (2,3,4) lie?

✅ Solution

All three coordinates are positive.

Therefore, it lies in the first octant.

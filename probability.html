1. Introduction to Probability

📖 Concept

Probability is a measure of how likely an event is to occur.

The probability of an event always lies between 0 and 1.

0 ≤ P(E) ≤ 1

For equally likely outcomes:

P(E) = Number of favourable outcomes / Total number of outcomes

✏️ Ex 1

A coin is tossed once. Find the probability of getting Head.

✅ Solution

Possible outcomes = {H, T}

Total outcomes = 2

Favourable outcomes = 1

P(H) = 1/2

Answer = 1/2

✏️ Ex 2

A die is thrown once. Find the probability of getting 4.

✅ Solution

Possible outcomes = 1, 2, 3, 4, 5, 6

Total outcomes = 6

Favourable outcomes = 1

P(4) = 1/6

🎲 🔢 ⭐

2. Sample Space

The set of all possible outcomes of an experiment is called the sample space.

It is usually denoted by S.

✏️ Ex 1

Write the sample space when a coin is tossed once.

✅ Solution

The possible outcomes are Head and Tail.

S = {H, T}

✏️ Ex 2

Write the sample space when a die is thrown once.

✅ Solution

S = {1, 2, 3, 4, 5, 6}

🎯 🔵 📌

3. Events

An event is a subset of the sample space.

An event may contain one or more outcomes.

✏️ Ex 1

A die is thrown. Find the event of getting an even number.

✅ Solution

Even numbers are 2, 4 and 6.

E = {2, 4, 6}

✏️ Ex 2

A die is thrown. Find the event of getting a number greater than 4.

✅ Solution

Numbers greater than 4 are 5 and 6.

E = {5, 6}

⭕ ❌ 🎯

4. Complementary Event

If E is an event, then its complement is the event that E does not occur.

P(E') = 1 − P(E)

P(E) + P(E') = 1

✏️ Ex 1

If P(E) = 3/5, find P(E').

✅ Solution

P(E') = 1 − P(E)

= 1 − 3/5

= 2/5

✏️ Ex 2

If the probability of passing an exam is 4/5, find the probability of not passing.

✅ Solution

P(not passing) = 1 − 4/5

= 1/5

➕ 🎯 🎲

5. Addition of Probabilities

For two mutually exclusive events E and F:

P(E ∪ F) = P(E) + P(F)

✏️ Ex 1

A die is thrown. Find the probability of getting 1 or 2.

✅ Solution

P(1) = 1/6

P(2) = 1/6

Therefore:

P(1 or 2) = 1/6 + 1/6

= 1/3

✏️ Ex 2

A die is thrown. Find the probability of getting 2 or 5.

✅ Solution

P(2) = 1/6

P(5) = 1/6

P(2 or 5) = 1/6 + 1/6

= 1/3

🎲 × 🎯 🔢

6. Multiplication of Probabilities

For independent events E and F:

P(E ∩ F) = P(E) × P(F)

✏️ Ex 1

A coin is tossed twice. Find the probability of getting Head both times.

✅ Solution

P(H) = 1/2

P(H and H) = 1/2 × 1/2

= 1/4

✏️ Ex 2

A coin is tossed twice. Find the probability of getting Tail both times.

✅ Solution

P(T) = 1/2

P(T and T) = 1/2 × 1/2

= 1/4

7. Probability Using Cards

A standard deck contains 52 playing cards.

There are 4 suits:

♠ Spades • ♥ Hearts • ♦ Diamonds • ♣ Clubs

Each suit contains 13 cards.

✏️ Ex 1

Find the probability of drawing an Ace from a standard deck of 52 cards.

✅ Solution

Number of Aces = 4

Total cards = 52

P(Ace) = 4/52

= 1/13

✏️ Ex 2

Find the probability of drawing a King.

✅ Solution

Number of Kings = 4

Total cards = 52

P(King) = 4/52

= 1/13

8. Important Properties

Probability follows some important properties which are useful while solving numerical problems.

0 ≤ P(E) ≤ 1

P(S) = 1

P(∅) = 0

P(E') = 1 − P(E)

✏️ Ex 1

Can the probability of an event be 1.5?

✅ Solution

Probability always lies between 0 and 1.

Since 1.5 > 1:

It cannot be a probability.

✏️ Ex 2

What is the probability of a sure event?

✅ Solution

A sure event always occurs.

P(E) = 1

1. Introduction to Inequalities

📖 Concept

An inequality is a mathematical statement that compares two quantities using symbols such as:

< less than

> greater than

≤ less than or equal to

≥ greater than or equal to

✏️ Ex 1

Solve:

x + 3 > 7

✅ Solution

x + 3 > 7

Subtract 3 from both sides:

x > 4

Answer: x > 4

✏️ Ex 2

Solve:

x − 5 ≤ 2

✅ Solution

x − 5 ≤ 2

Add 5 to both sides:

x ≤ 7

Answer: x ≤ 7

✖️ ➗ 🔄

2. Rules of Inequalities

When the same number is added or subtracted from both sides, the direction of inequality remains unchanged.

When both sides are multiplied or divided by a negative number, the direction of inequality is reversed.

If a > b,

then −a < −b

The inequality sign reverses when multiplying or dividing by a negative number.

✏️ Ex 1

Solve:

−2x > 8

✅ Solution

−2x > 8

Divide by −2.

Since we divide by a negative number, the sign reverses:

x < −4

Answer: x < −4

✏️ Ex 2

Solve:

−3x + 5 ≤ 14

✅ Solution

−3x + 5 ≤ 14

−3x ≤ 9

Divide by −3 and reverse the sign:

x ≥ −3

📏 🔢 📍

3. Solution on the Number Line

The solution of an inequality can be represented on a number line.

For x > a, the point a is not included and the arrow goes towards the right.

For x ≥ a, the point a is included and the arrow goes towards the right.

✏️ Ex 1

Represent:

x > 3

✅ Solution

Since x is greater than 3, 3 is not included.

Use an open circle at 3 and shade towards the right.

Interval form: (3, ∞)

✏️ Ex 2

Represent:

x ≤ −2

✅ Solution

Since x can be equal to −2, use a closed circle at −2.

Shade towards the left.

Interval form: (−∞, −2]

🔢 ➕ ➖

4. Linear Inequalities in One Variable

A linear inequality in one variable can be written in the form:

ax + b > 0

ax + b < 0

ax + b ≥ 0

ax + b ≤ 0

✏️ Ex 1

Solve:

3x + 4 < 16

✅ Solution

3x + 4 < 16

3x < 12

x < 4

Answer: x < 4

✏️ Ex 2

Solve:

5x − 7 ≥ 18

✅ Solution

5x − 7 ≥ 18

5x ≥ 25

x ≥ 5

🔗 ⚖️ 🔢

5. Compound Inequalities

A compound inequality contains two or more inequalities connected together.

Example:

2 < x < 7

✏️ Ex 1

Solve:

2 < x + 1 < 7

✅ Solution

Subtract 1 from all three parts:

2 − 1 < x + 1 − 1 < 7 − 1

1 < x < 6

Answer: 1 < x < 6

✏️ Ex 2 — 🔴 Hard

Solve:

−5 ≤ 2x + 1 < 9

✅ Solution

Subtract 1 throughout:

−6 ≤ 2x < 8

Divide throughout by 2:

−3 ≤ x < 4

📦 🔢 ⚖️

6. Word Problems on Inequalities

Many real-life problems involving maximum, minimum, limits, age, money, marks or quantities can be represented using inequalities.

✏️ Ex 1

A number increased by 5 is greater than 12. Find the possible values of the number.

✅ Solution

Let the number be x.

According to the question:

x + 5 > 12

x > 7

Therefore, the number is greater than 7.

✏️ Ex 2 — 🔴 Hard

A student needs at least 40 marks to pass. If the student has already scored 27 marks, how many more marks are required?

✅ Solution

Let additional marks be x.

27 + x ≥ 40

x ≥ 13

At least 13 more marks are required.

⭐ 📌 🧠

⭐ Important Points

1. Adding or subtracting the same number does not change the inequality sign.

2. Multiplying or dividing by a positive number does not change the sign.

3. Multiplying or dividing by a negative number reverses the sign.

4. Open circle means the endpoint is not included.

5. Closed circle means the endpoint is included.

6. Always check the final answer on the number line when required.

1. Angle and Its Measurement

📐 θ 🔄

📖 Concept

An angle is formed when a ray rotates about its initial point. Angles can be measured in degrees and radians.

180° = π radians

1° = π/180 radians

1 radian = 180°/π

✏️ Ex 1

Convert 60° into radians.

✅ Solution

60° × π/180°

= π/3

Answer: π/3 radians

✏️ Ex 2

Convert π/4 radians into degrees.

✅ Solution

π/4 × 180°/π

= 45°

Answer: 45°

2. Trigonometric Ratios

sin θ
cos θ
tan θ

📖 Basic Ratios

For an acute angle θ in a right-angled triangle:

sin θ = Perpendicular / Hypotenuse

cos θ = Base / Hypotenuse

tan θ = Perpendicular / Base

cosec θ = 1/sin θ

sec θ = 1/cos θ

cot θ = 1/tan θ

✏️ Ex 1

In a right triangle, perpendicular = 3 and hypotenuse = 5. Find sin θ.

✅ Solution

sin θ = P/H

= 3/5

Answer: sin θ = 3/5

✏️ Ex 2

If cos θ = 4/5, find sec θ.

✅ Solution

sec θ = 1/cos θ

= 1/(4/5)

= 5/4

3. Signs of Trigonometric Functions

I 😊
II 😄
III 😐
IV 🙂

📖 Quadrants

The signs of trigonometric functions depend on the quadrant in which the angle lies.

I → All positive

II → sin and cosec positive

III → tan and cot positive

IV → cos and sec positive

✏️ Ex 1

In which quadrant is sin θ positive and cos θ negative?

✅ Solution

sin is positive and cos is negative in the second quadrant.

Answer: II quadrant

✏️ Ex 2

In which quadrant is tan θ negative?

✅ Solution

tan is positive in I and III. Therefore it is negative in II and IV.

Answer: II and IV quadrants

4. Trigonometric Values of Standard Angles

0° 30° 45° 60° 90°
sin 0° = 0

sin 30° = 1/2

sin 45° = 1/√2

sin 60° = √3/2

sin 90° = 1

cos 0° = 1

✏️ Ex 1

Find sin 60° + cos 60°.

✅ Solution

sin 60° = √3/2

cos 60° = 1/2

Therefore:

(√3+1)/2

Answer: (√3+1)/2

✏️ Ex 2

Find tan 45° + sin 30°.

✅ Solution

tan 45° = 1

sin 30° = 1/2

1 + 1/2 = 3/2

Answer: 3/2

5. Fundamental Trigonometric Identities

🔢 = 🔢
sin²θ + cos²θ = 1

1 + tan²θ = sec²θ

1 + cot²θ = cosec²θ

✏️ Ex 1

If sin θ = 3/5 and θ is acute, find cos θ.

✅ Solution

sin²θ + cos²θ = 1

(3/5)² + cos²θ = 1

9/25 + cos²θ = 1

cos²θ = 16/25

Since θ is acute:

cos θ = 4/5

✏️ Ex 2

If tan θ = 3/4, find sec θ.

✅ Solution

1 + tan²θ = sec²θ

1 + 9/16 = sec²θ

25/16 = sec²θ

For an acute angle:

sec θ = 5/4

6. Trigonometric Functions of Negative Angles

+θ ↔ −θ
sin(−θ) = −sin θ

cos(−θ) = cos θ

tan(−θ) = −tan θ

cosec(−θ) = −cosec θ

sec(−θ) = sec θ

cot(−θ) = −cot θ

✏️ Ex 1

Find sin(−30°).

✅ Solution

sin(−θ)=−sinθ

sin(−30°)=−sin30°

= −1/2

✏️ Ex 2

Find cos(−60°).

✅ Solution

cos(−θ)=cosθ

cos(−60°)=cos60°

= 1/2

7. Compound Angles

(A+B) ➕ (A−B)
sin(A+B)=sinA cosB + cosA sinB

sin(A−B)=sinA cosB − cosA sinB

cos(A+B)=cosA cosB − sinA sinB

cos(A−B)=cosA cosB + sinA sinB

tan(A+B)=(tanA+tanB)/(1−tanA tanB)

tan(A−B)=(tanA−tanB)/(1+tanA tanB)

✏️ Ex 1

Find sin(45°+30°).

✅ Solution

sin(A+B)=sinA cosB + cosA sinB

= (1/√2)(√3/2) + (1/√2)(1/2)

= (√3+1)/(2√2)

✏️ Ex 2

Find cos(60°−30°).

✅ Solution

cos(60°−30°)=cos30°

= √3/2

8. Double Angle Formulae

2θ 🔄
sin 2θ = 2sinθ cosθ

cos 2θ = cos²θ − sin²θ

cos 2θ = 2cos²θ − 1

cos 2θ = 1 − 2sin²θ

tan 2θ = 2tanθ/(1−tan²θ)

✏️ Ex 1

If sin θ = 3/5 and cos θ = 4/5, find sin 2θ.

✅ Solution

sin2θ = 2sinθ cosθ

= 2 × 3/5 × 4/5

= 24/25

✏️ Ex 2

If cos θ = 3/5, find cos 2θ.

✅ Solution

cos2θ = 2cos²θ − 1

= 2(9/25) − 1

= 18/25 − 25/25

= −7/25

9. Half Angle Formulae

θ/2
sin²(θ/2) = (1−cosθ)/2

cos²(θ/2) = (1+cosθ)/2

tan²(θ/2) = (1−cosθ)/(1+cosθ)

✏️ Ex 1

Find sin²(θ/2) if cos θ = 3/5.

✅ Solution

sin²(θ/2) = (1−cosθ)/2

= (1−3/5)/2

= (2/5)/2

= 1/5

✏️ Ex 2

Find cos²(θ/2) if cos θ = 1/3.

✅ Solution

cos²(θ/2) = (1+cosθ)/2

= (1+1/3)/2

= (4/3)/2

= 2/3

🔥 Mixed Questions

Questions based on different topics of Trigonometric Functions.

✏️ Mixed Ex 1

If sin θ = 3/5 and θ is acute, find tan θ and sec θ.

✅ Solution

sin θ = 3/5

Using sin²θ + cos²θ = 1:

cos θ = 4/5

tan θ = sinθ/cosθ

= (3/5)/(4/5)

= 3/4

sec θ = 1/cosθ

= 5/4

✏️ Mixed Ex 2

Find the value of: sin 60° cos 30° + cos 60° sin 30°.

✅ Solution

Using:

sin(A+B)=sinA cosB + cosA sinB

Given expression = sin(60°+30°)

= sin90°

= 1

✏️ Mixed Ex 3

If tan θ = 1/2, find tan 2θ.

✅ Solution

tan2θ = 2tanθ/(1−tan²θ)

= 2(1/2)/(1−1/4)

= 1/(3/4)

= 4/3

✏️ Mixed Ex 4

Prove: (1−cos2θ)/(sin2θ) = tanθ.

✅ Solution

1−cos2θ = 2sin²θ

sin2θ = 2sinθ cosθ

Therefore:

(1−cos2θ)/(sin2θ)

= 2sin²θ/(2sinθ cosθ)

= sinθ/cosθ

= tanθ

✏️ Mixed Ex 5 — 🔴 JEE Level

If tan θ = 3/4 and θ lies in the first quadrant, find sin 2θ and cos 2θ.

✅ Solution

tanθ = 3/4

Take perpendicular = 3 and base = 4.

Hypotenuse = 5

Therefore:

sinθ = 3/5

cosθ = 4/5

sin2θ = 2sinθ cosθ

= 2×3/5×4/5

sin2θ = 24/25

cos2θ = cos²θ−sin²θ

= 16/25−9/25

cos2θ = 7/25

✏️ Mixed Ex 6 — 🔴 JEE Level

Solve 2sin²x = 1 for 0 ≤ x ≤ 2π.

✅ Solution

2sin²x = 1

sin²x = 1/2

sinx = ±1/√2

For 0 ≤ x ≤ 2π:

x = π/4, 3π/4, 5π/4, 7π/4

Answer: x = π/4, 3π/4, 5π/4, 7π/4

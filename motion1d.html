🚗 Motion in a Straight Line

Class 11 Physics • Lernix11

1. Position and Reference Point

📍 ➡️ 🏠

📖 Definition

The position of an object describes its location with respect to a chosen reference point or reference frame.

⭐ Important:

Position can change when an object moves from one location to another.

2. Distance

🚶 ➡️ ➡️ ➡️

📖 Definition

Distance is the total length of the actual path travelled by an object.

⭐ Important:

Distance is a scalar quantity and is always non-negative.

3. Displacement

📍 ➡️ 🎯

📖 Definition

Displacement is the change in position of an object from its initial position to its final position.

Displacement = Final Position − Initial Position
⭐ Important:

Displacement is a vector quantity. Its magnitude can be zero even when the object has travelled some distance.

4. Speed

🏎️ 💨

📖 Definition

Speed is the distance travelled by an object per unit time.

Speed = Distance / Time
⭐ Important:

Speed is a scalar quantity.

5. Velocity

🚗 ➡️

📖 Definition

Velocity is the rate of change of displacement with respect to time.

Average Velocity = Displacement / Time
⭐ Important:

Velocity is a vector quantity and has both magnitude and direction.

6. Acceleration

🚗 💨 🚀

📖 Definition

Acceleration is the rate of change of velocity with respect to time.

a = (v − u) / t
⭐ Important:

Acceleration can be positive, negative or zero.

7. Uniform and Non-uniform Motion

🚗 ➡️ ➡️ ➡️

📖 Definition

In uniform motion an object covers equal distances in equal intervals of time. In non-uniform motion it does not.

⭐ Important:

Uniform motion has constant velocity when the direction also remains unchanged.

8. Equations of Motion

📈 🧮
v = u + at

s = ut + ½at²

v² = u² + 2as
⭐ Symbols:

u = initial velocity
v = final velocity
a = acceleration
t = time
s = displacement

9. Motion Graphs

📊 📈

📖 Important Concept

Graphs help us understand how position, velocity and acceleration change with time.

⭐ Important:

The slope of a position-time graph gives velocity. The slope of a velocity-time graph gives acceleration.

10. Relative Motion in One Dimension

🚗 ➡️ 🚙

📖 Definition

Relative velocity describes the velocity of one object as observed from another moving object.

Relative Velocity = Velocity of A − Velocity of B

⭐ Quick Revision

🧠 ⚡
Remember:

Speed = Distance / Time

Velocity = Displacement / Time

a = (v − u) / t

1. Cartesian Product of Sets

A × B 🔗

📖 Concept

The Cartesian product of two sets A and B is the set of all ordered pairs (a,b), where a ∈ A and b ∈ B.

A × B = {(a,b) : a ∈ A, b ∈ B}

If n(A)=m and n(B)=n, then
n(A × B)=mn

✏️ Ex 1

If A = {1,2} and B = {3,4}, find A × B.

✅ Solution

Pair each element of A with every element of B.

A × B = {(1,3),(1,4),(2,3),(2,4)}

Answer: {(1,3),(1,4),(2,3),(2,4)}

✏️ Ex 2

If n(A)=3 and n(B)=4, find n(A × B).

✅ Solution

n(A × B) = n(A) × n(B)

= 3 × 4

= 12

Answer: 12

2. Relations

A ↔ B

📖 Definition

A relation from set A to set B is any subset of A × B.

R ⊆ A × B

✏️ Ex 1

A = {1,2} and B = {3,4}. Write one possible relation from A to B.

✅ Solution

A × B = {(1,3),(1,4),(2,3),(2,4)}

Any subset of A × B can be a relation.

Example: R = {(1,3),(2,4)}

✏️ Ex 2

If n(A × B)=12, what is the maximum number of ordered pairs that a relation from A to B can contain?

✅ Solution

A relation is a subset of A × B.

Therefore maximum number of ordered pairs = n(A × B).

Answer: 12

3. Domain, Codomain and Range

A → B

📖 Important Terms

Domain = set of first components.

Codomain = target set.

Range = set of actual second components obtained.

✏️ Ex 1

R = {(1,2),(2,4),(3,6)}. Find the domain and range.

✅ Solution

First components = {1,2,3}

Second components = {2,4,6}

Domain = {1,2,3}
Range = {2,4,6}

✏️ Ex 2

If R = {(2,5),(3,5),(4,6)}, find the range.

✅ Solution

The second components are 5,5 and 6.

Repeated elements are written only once.

Range = {5,6}

4. Functions

A → B → C

📖 Definition

A function from A to B assigns exactly one element of B to each element of A.

f : A → B

Every element of A must have exactly one image in B.

✏️ Ex 1

Is {(1,2),(2,3),(3,4)} a function from {1,2,3} to {2,3,4}?

✅ Solution

Each element of the domain has exactly one image.

Answer: Yes, it is a function.

✏️ Ex 2

Is {(1,2),(1,3),(2,4)} a function?

✅ Solution

The element 1 has two images, 2 and 3.

A function cannot assign two different images to one input.

Answer: No, it is not a function.

5. Real Functions

ℝ → ℝ

📖 Concept

A real function is a function whose domain and range are subsets of the real numbers.

✏️ Ex 1

Find f(3) if f(x)=2x+5.

✅ Solution

f(3) = 2(3)+5

= 6+5

f(3)=11

✏️ Ex 2

Find f(-2) if f(x)=x²+3x+1.

✅ Solution

f(-2)=(-2)²+3(-2)+1

=4-6+1

f(-2)=-1

6. Algebra of Functions

f + g • f − g

📖 Concept

For functions f and g, we can define their sum, difference, product and quotient wherever these operations are defined.

(f+g)(x)=f(x)+g(x)

(f−g)(x)=f(x)−g(x)

(fg)(x)=f(x)g(x)

✏️ Ex 1

If f(x)=x+2 and g(x)=x−1, find (f+g)(x).

✅ Solution

(f+g)(x) = f(x)+g(x)

= (x+2)+(x−1)

= 2x+1

Answer: 2x+1

✏️ Ex 2

If f(x)=2x and g(x)=x+3, find (fg)(2).

✅ Solution

f(2)=4

g(2)=5

(fg)(2)=4×5

Answer: 20

7. One-One Function

1 → A
2 → B
3 → C

📖 Definition

A function is one-one if different elements of the domain have different images.

✏️ Ex 1

Check whether f(x)=2x+1 is one-one on R.

✅ Solution

Let f(a)=f(b).

2a+1=2b+1

2a=2b

a=b

Therefore f(x)=2x+1 is one-one.

✏️ Ex 2

Is f(x)=x² one-one on R?

✅ Solution

f(1)=1 and f(-1)=1.

But 1 ≠ -1.

Therefore f(x)=x² is not one-one on R.

8. Many-One Function

1 ↘
2 → A
3 ↗

📖 Definition

A function is many-one if two or more different elements of the domain can have the same image.

✏️ Ex 1

Check whether f(x)=x² is many-one on R.

✅ Solution

f(1)=1 and f(-1)=1.

Two different inputs have the same output.

Answer: It is many-one.

✏️ Ex 2

Is f(x)=x³ many-one on R?

✅ Solution

If a³=b³, then a=b.

Thus different inputs cannot have the same output.

Answer: No, it is one-one.

9. Into Function

A → B
⚪ ⚪ ⚪

📖 Definition

A function is into if at least one element of the codomain is not an image of any element of the domain.

✏️ Ex 1

A={1,2}, B={a,b,c} and f={(1,a),(2,b)}. Is f into?

✅ Solution

Element c of B has no pre-image.

Answer: Yes, f is into.

✏️ Ex 2

If every element of codomain has a pre-image, can the function be into?

✅ Solution

No. If every codomain element has a pre-image, the function is onto.

Answer: No.

10. Onto Function

A → B
⚪ ← ⚪

📖 Definition

A function is onto if every element of the codomain is the image of at least one element of the domain.

✏️ Ex 1

f:R→R defined by f(x)=x+2. Is it onto?

✅ Solution

Let y be any real number.

y=x+2

x=y−2

Since y−2 is real, every real y has a pre-image.

Therefore f is onto.

✏️ Ex 2

Is f:R→R defined by f(x)=x² onto?

✅ Solution

The range of x² is [0,∞).

Negative real numbers are not obtained.

Therefore f is not onto R.

11. Into and Onto: Quick Difference

↔️ 🔍
Into → Some codomain elements have no pre-image.

Onto → Every codomain element has at least one pre-image.

✏️ Ex 1

A function has range equal to its codomain. Is it onto?

✅ Solution

If range = codomain, every codomain element has a pre-image.

Answer: Yes, it is onto.

✏️ Ex 2

A function has range smaller than its codomain. Is it onto?

✅ Solution

Some codomain elements are not images.

Answer: No, it is into.

12. Composition of Functions

f → g → h

📖 Concept

If f and g are functions, their composition is written as (g∘f)(x)=g(f(x)).

(g∘f)(x)=g(f(x))

✏️ Ex 1

If f(x)=x+1 and g(x)=2x, find (g∘f)(x).

✅ Solution

(g∘f)(x)=g(f(x))

=g(x+1)

=2(x+1)

=2x+2

✏️ Ex 2

If f(x)=x² and g(x)=x+3, find (g∘f)(2).

✅ Solution

f(2)=4

g(4)=7

(g∘f)(2)=7

13. Identity Function

x → x

📖 Definition

A function which maps every element to itself is called the identity function.

I(x)=x

✏️ Ex 1

Find I(7) for the identity function I(x)=x.

✅ Solution

I(7)=7

Answer: 7

✏️ Ex 2

Find I(-5).

✅ Solution

I(-5)=-5

Answer: -5

🔥 Mixed Questions

Questions based on different topics of Relations and Functions.

✏️ Mixed Ex 1

A={1,2,3} and B={2,4,6}. Define f:A→B by f(x)=2x. Find the range and state whether f is one-one and onto.

✅ Solution

f(1)=2
f(2)=4
f(3)=6

Range = {2,4,6}

All outputs are different, so f is one-one.

Range = B, so f is onto.

Answer: Range={2,4,6}; f is one-one and onto.

✏️ Mixed Ex 2

If f(x)=2x+1 and g(x)=x², find (g∘f)(2).

✅ Solution

f(2)=2(2)+1=5

g(5)=5²=25

Answer: 25

✏️ Mixed Ex 3

Let A={1,2,3,4} and B={1,4,9,16}. Is f:A→B defined by f(x)=x² one-one and onto?

✅ Solution

f(1)=1
f(2)=4
f(3)=9
f(4)=16

All outputs are different.

Range = {1,4,9,16}=B.

Answer: f is both one-one and onto.

✏️ Mixed Ex 4

If A has 3 elements and B has 2 elements, find the number of elements in A×B and the maximum possible number of ordered pairs in a relation from A to B.

✅ Solution

n(A×B)=n(A)×n(B)

=3×2

=6

A relation is a subset of A×B.

Answer: 6 elements; maximum 6 ordered pairs.

✏️ Mixed Ex 5 — 🔴 JEE Level

Let f:R→R be defined by f(x)=x²+2x+3. Determine whether f is one-one or not.

✅ Solution

Complete the square:

f(x)=x²+2x+3

=(x+1)²+2

Now:

f(0)=3

f(-2)=4-4+3=3

But 0 ≠ -2.

Therefore two different inputs have the same output.

Answer: f is not one-one on R.

✏️ Mixed Ex 6 — 🔴 JEE Level

If f(x)=3x−2 and g(x)=(x+2)/3, find (f∘g)(x) and (g∘f)(x).

✅ Solution

(f∘g)(x)=f(g(x))

=3[(x+2)/3]−2

=x+2−2

=x

Now:

(g∘f)(x)=g(f(x))

=[(3x−2)+2]/3

=3x/3

=x

Answer:
(f∘g)(x)=x
(g∘f)(x)=x

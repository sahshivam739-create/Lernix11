1. Principle of Mathematical Induction

📖 Concept

Mathematical induction is a method used to prove that a statement is true for every natural number n.

It consists mainly of two steps:

Step 1: Prove the statement for the first value, usually n = 1.

Step 2: Assume it is true for n = k and prove it for n = k + 1.

P(1) is true

P(k) ⇒ P(k+1)

Therefore P(n) is true for all natural numbers n ≥ 1.

✏️ Ex 1

Prove that:

1 + 2 + 3 + ... + n = n(n+1)/2

✅ Solution

Step 1: For n = 1

LHS = 1

RHS = 1(1+1)/2 = 1

Therefore P(1) is true.

Step 2: Assume P(k) is true.

1 + 2 + ... + k = k(k+1)/2

Step 3: Prove P(k+1).

1 + 2 + ... + k + (k+1)

= k(k+1)/2 + (k+1)

= (k+1)(k+2)/2

Hence proved for all n ≥ 1.

✏️ Ex 2

Prove that:

1 + 3 + 5 + ... + (2n−1) = n²

✅ Solution

For n = 1:

LHS = 1

RHS = 1² = 1

So P(1) is true.

Assume P(k):

1 + 3 + ... + (2k−1) = k²

For k+1:

1 + 3 + ... + (2k−1) + (2k+1)

= k² + 2k + 1

= (k+1)²

Hence proved.

2. Sum of Natural Numbers

1 + 2 + 3 + ... + n = n(n+1)/2

✏️ Ex 1

Prove that:

1 + 2 + 3 + ... + n = n(n+1)/2

✅ Solution

For n=1:

1 = 1(2)/2

Assume:

1+2+...+k = k(k+1)/2

For k+1:

k(k+1)/2 +(k+1)

= (k+1)(k+2)/2

Hence proved.

✏️ Ex 2

Find the sum:

1 + 2 + 3 + ... + 100

✅ Solution

Sum = n(n+1)/2

= 100×101/2

= 5050

3. Sum of Squares

1² + 2² + 3² + ... + n² = n(n+1)(2n+1)/6

✏️ Ex 1

Prove that:

1² + 2² + ... + n² = n(n+1)(2n+1)/6

✅ Solution

For n=1:

LHS = 1

RHS = 1×2×3/6 = 1

Assume:

1²+2²+...+k² = k(k+1)(2k+1)/6

For k+1:

k(k+1)(2k+1)/6 + (k+1)²

= (k+1)(2k²+7k+6)/6

= (k+1)(k+2)(2k+3)/6

Hence proved.

✏️ Ex 2

Find:

1² + 2² + 3² + 4² + 5²

✅ Solution

= 5×6×11/6

= 55

4. Sum of Cubes

1³ + 2³ + 3³ + ... + n³ = [n(n+1)/2]²

✏️ Ex 1

Prove that:

1³ + 2³ + ... + n³ = [n(n+1)/2]²

✅ Solution

For n=1:

1³ = [1×2/2]² = 1

Assume:

1³+...+k³ = [k(k+1)/2]²

For k+1:

[k(k+1)/2]² + (k+1)³

= (k+1)²(k+2)²/4

= [(k+1)(k+2)/2]²

Hence proved.

✏️ Ex 2

Find:

1³ + 2³ + 3³ + 4³

✅ Solution

= [4×5/2]²

= 10²

= 100

5. Divisibility by Mathematical Induction

Induction can be used to prove that an expression is divisible by a particular number for every natural number n.

✏️ Ex 1 — 🔴 Hard

Prove that 3ⁿ − 1 is divisible by 2 for every natural number n.

✅ Solution

For n=1:

3−1 = 2

Assume:

3ᵏ−1 = 2m

For k+1:

3ᵏ⁺¹−1 = 3(3ᵏ−1)+2

= 3(2m)+2

= 2(3m+1)

Hence divisible by 2.

✏️ Ex 2 — 🔴 Hard

Prove that 5ⁿ − 1 is divisible by 4 for every natural number n.

✅ Solution

For n=1:

5−1 = 4

Assume:

5ᵏ−1 = 4m

For k+1:

5ᵏ⁺¹−1 = 5(5ᵏ−1)+4

= 5(4m)+4

= 4(5m+1)

Hence divisible by 4.

6. Induction in Inequalities

Mathematical induction can also be used to prove inequalities involving natural numbers.

✏️ Ex 1 — 🔴 Hard

Prove that:

2ⁿ ≥ n+1

✅ Solution

For n=1:

2 ≥ 2

Assume:

2ᵏ ≥ k+1

For k+1:

2ᵏ⁺¹ = 2×2ᵏ

≥ 2(k+1)

≥ k+2

Hence proved.

✏️ Ex 2

Prove that:

n² ≥ 2n−1

✅ Solution

For n=1:

1 ≥ 1

Assume:

k² ≥ 2k−1

For k+1:

(k+1)² = k²+2k+1

≥ 2k−1+2k+1

= 4k

Since k≥1, 4k≥2k+1.

Hence proved.

⭐ 📌 🧠

⭐ Important Points

1. First prove P(1).

2. Assume P(k) is true.

3. Prove P(k+1) using the assumption.

4. Clearly write the final conclusion.

5. Induction is generally used for statements involving natural numbers.

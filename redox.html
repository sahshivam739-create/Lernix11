⚡ Redox Reactions

Class 11 Chemistry • Lernix11

1. Oxidation

⚛️ ➖ ➡️ ⚡

📖 Definition

Oxidation is a process involving loss of electrons, increase in oxidation number or addition of oxygen.

⭐ Remember:

Oxidation → Loss of electrons

2. Reduction

⚡ ➡️ ⚛️ ➕

📖 Definition

Reduction is a process involving gain of electrons, decrease in oxidation number or removal of oxygen.

⭐ Remember:

Reduction → Gain of electrons

3. Redox Reaction

⚡ ⇌ ⚛️

📖 Definition

A reaction in which oxidation and reduction occur simultaneously is called a redox reaction.

4. Oxidising Agent

🧪 ➡️ ⚡

📖 Definition

An oxidising agent is a substance that causes oxidation of another substance and itself undergoes reduction.

⭐ Key Point:

Oxidising agent → Gets reduced

5. Reducing Agent

⚡ ➡️ 🧪

📖 Definition

A reducing agent is a substance that causes reduction of another substance and itself undergoes oxidation.

⭐ Key Point:

Reducing agent → Gets oxidised

6. Oxidation Number

🔢 ⚛️ ➕➖

📖 Definition

Oxidation number is the apparent charge assigned to an atom in a compound or ion according to certain rules.

7. Rules for Oxidation Number

📋 🔢 ⚛️
⭐ Important Rules:

1. Oxidation number of an element in its free state is zero.

2. Oxidation number of a monoatomic ion equals its charge.

3. Oxygen is generally −2.

4. Hydrogen is generally +1.

5. Sum of oxidation numbers in a neutral compound is zero.

6. Sum of oxidation numbers in a polyatomic ion equals its charge.

8. Disproportionation Reaction

⚛️ ➡️ ⚡ ➕ ➖

📖 Definition

A reaction in which the same element is simultaneously oxidised and reduced is called a disproportionation reaction.

⭐ Example:

Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O

9. Balancing Redox Reactions

⚖️ ⚡ 🧪

📖 Methods

Redox reactions can be balanced using the oxidation number method or the ion-electron method.

10. Oxidation Number Method

🔢 ➡️ ⚖️
⭐ Main Steps:

1. Write the skeletal equation.

2. Assign oxidation numbers.

3. Identify oxidation and reduction.

4. Equalise the increase and decrease in oxidation number.

5. Balance the remaining atoms and charges.

11. Ion-Electron Method

➕ ➖ ⚡ ⚖️
⭐ Main Steps:

1. Split the reaction into oxidation and reduction half-reactions.

2. Balance atoms other than H and O.

3. Balance O using H₂O.

4. Balance H using H⁺ in acidic medium.

5. Balance charge using electrons.

6. Add the half-reactions.

12. Redox in Electrochemical Processes

⚡ 🔋 ➕ ➖

📖 Concept

Oxidation and reduction reactions are fundamental processes in electrochemical cells.

⭐ Remember:

Oxidation occurs at the anode.

Reduction occurs at the cathode.

⭐ Quick Revision

🧠 ⚡ 🔢
Oxidation → Loss of electrons

Reduction → Gain of electrons

Oxidising agent → Gets reduced

Reducing agent → Gets oxidised

Oxidation → Anode

Reduction → Cathode
